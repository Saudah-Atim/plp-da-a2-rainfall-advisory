Rainfall Analysis and Planting Advisory

 This project looks at rainfall data from five counties to understand which months are suitable for planting.

How to Run the Notebook: Open rainfall_analysis.ipynb in Google Colab and run all the cells from top to bottom to see the results.

Planting Advisory: April receives more rainfall in most of the counties, making it a good month for farmers to prepare for planting. Areas with less rainfall may need extra water.
